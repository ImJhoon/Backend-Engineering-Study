# 영화 예매 시스템 요구사항 명세서

## 1. 개요

- 사용자는 상영 중인 영화를 조회하고 원하는 일정과 좌석을 선택해 예매할 수 있다.
- 예매 확정은 로그인한 회원만 가능하다.
- MVP에서는 예매 완료와 동시에 결제가 완료된 것으로 간주한다.
- 한 번에 최소 1석, 최대 8석까지 예매할 수 있다.

## 2. 기능 요구사항

### 메인페이지

#### FR-MAIN-001 영화 목록 조회

- 현재 상영 중인 영화를 카드 형태로 표시한다.
- 카드에는 포스터, 제목, 관람 등급, 상영 시간, 개봉일, 장르를 표시한다.

#### FR-MAIN-002 영화 상세 정보 조회

- 상영 가능한 영화만 개봉일 또는 사전에 정의한 순서로 표시한다.
- 영화 카드 선택 시 제목, 포스터, 줄거리, 장르, 감독, 출연진, 상영 시간, 관람 등급, 개봉일을 표시한다.
- 상세 화면에 `예매하기` 버튼을 제공한다.
- 버튼 선택 시 해당 영화가 선택된 상태로 예매페이지로 이동한다.

#### FR-MAIN-003 로그인 상태 표시

- 비로그인 상태에서는 `로그인`, `회원가입` 버튼을 표시한다.
- 로그인 상태에서는 사용자 닉네임과 `로그아웃` 버튼을 표시한다.
- 유효한 인증 정보가 있으면 새로고침 후에도 로그인 상태를 유지한다.

#### FR-MAIN-004 빈 목록 및 오류 처리

- 상영 중인 영화가 없으면 안내 메시지를 표시한다.
- 영화 목록 조회 실패 시 오류 메시지와 재시도 버튼을 표시한다.

### 회원가입

#### FR-SIGNUP-001 회원가입 정보 입력

- 이메일, 비밀번호, 비밀번호 확인, 닉네임을 입력받는다.
- 모든 항목은 필수 입력값이다.

#### FR-SIGNUP-002 이메일 검증

- 이메일 앞뒤 공백을 제거한다.
- 이메일 형식을 검증한다.
- 이미 가입된 이메일은 사용할 수 없다.

#### FR-SIGNUP-003 비밀번호 검증

- 비밀번호는 8자 이상이며 영문과 숫자를 각각 하나 이상 포함해야 한다.
- 비밀번호와 비밀번호 확인 값이 일치해야 한다.
- 비밀번호는 단방향 해시하여 저장하고 평문으로 저장하지 않는다.

#### FR-SIGNUP-004 닉네임 검증

- 닉네임 앞뒤 공백을 제거한다.
- 닉네임은 2자 이상 20자 이하여야 한다.
- 이미 사용 중인 닉네임은 사용할 수 없다.

#### FR-SIGNUP-005 회원가입 완료

- 모든 입력값이 유효하면 회원 정보를 저장하고 로그인 페이지로 이동한다.
- 실패 시 원인을 사용자에게 표시한다.
- 이메일과 닉네임에 고유 제약조건을 적용하여 중복 회원 생성을 방지한다.

### 로그인 및 로그아웃

#### FR-LOGIN-001 로그인

- 이메일과 비밀번호로 로그인한다.
- 이메일 또는 비밀번호가 일치하지 않으면 동일한 오류 메시지를 표시한다.
- 로그인 성공 시 인증 정보를 발급한다.
- 로그인 전 접근하려던 페이지가 있으면 해당 페이지로, 없으면 메인페이지로 이동한다.

#### FR-LOGIN-002 로그인 상태 유지

- 인증 정보가 유효한 동안 로그인 상태를 유지한다.
- 인증 정보가 만료되거나 유효하지 않으면 다시 로그인하도록 처리한다.
- 보호된 API는 인증된 회원만 호출할 수 있다.

#### FR-LOGIN-003 로그아웃

- 로그아웃 시 클라이언트에 저장된 인증 정보를 제거한다.
- 로그아웃 후 보호된 페이지에 접근하면 로그인 페이지로 이동한다.

### 예매페이지

#### FR-BOOKING-001 영화 선택

- 상영 일정이 존재하는 영화만 선택할 수 있다.
- 메인페이지에서 이동한 경우 선택한 영화를 기본값으로 설정한다.
- 영화를 변경하면 선택한 날짜, 일정, 좌석을 초기화한다.

#### FR-BOOKING-002 상영 날짜 선택

- 선택한 영화의 상영 일정이 있는 날짜만 조회하고 선택할 수 있다.
- 현재 날짜 이전의 날짜는 선택할 수 없다.
- 날짜를 변경하면 선택한 일정과 좌석을 초기화한다.

#### FR-BOOKING-003 상영 시간 선택

- 일정별 시작 시간, 종료 예정 시간, 상영관, 남은 좌석 수를 표시한다.
- 이미 시작했거나 매진된 일정은 선택할 수 없다.

#### FR-BOOKING-004 좌석 조회

- 상영 일정 선택 시 해당 상영관의 좌석 상태를 조회한다.
- 좌석 상태를 `선택 가능`, `사용자 선택`, `예매 완료`, `사용 불가`로 구분한다.
- 예매 완료 또는 사용 불가 좌석은 선택할 수 없다.

#### FR-BOOKING-005 좌석 선택

- 선택 가능한 좌석을 1석 이상, 최대 8석까지 선택할 수 있다.
- 선택한 좌석을 다시 누르면 선택을 해제한다.
- 선택한 좌석 번호, 좌석 수, 총 금액을 표시한다.
- 총 금액은 선택한 좌석 가격의 합계로 계산한다.

#### FR-BOOKING-006 예매 정보 확인

- 영화 제목, 상영 날짜와 시간, 상영관, 좌석, 인원수, 총 금액을 표시한다.
- 영화, 일정, 좌석이 모두 선택된 경우에만 예매 확정 버튼을 활성화한다.

#### FR-BOOKING-007 예매 확정

- 로그인한 회원만 예매를 확정할 수 있다.
- 서버에서 상영 일정과 모든 좌석의 예매 가능 여부를 다시 검증한다.
- 서버가 좌석 가격을 기준으로 총 금액을 다시 계산한다.
- 성공 시 예매 정보를 저장하고 고유한 예매번호를 생성한다.

#### FR-BOOKING-008 동시 예매 처리

- 여러 사용자가 같은 좌석을 선택할 수 있지만 최종 예매는 한 명만 성공해야 한다.
- 요청 좌석 중 하나라도 예매할 수 없으면 전체 예매를 실패 처리한다.
- 예매와 예매 좌석 저장을 하나의 트랜잭션으로 처리하여 부분 예매를 방지한다.
- 실패 시 최신 좌석 상태와 재선택 안내를 표시한다.

#### FR-BOOKING-009 예매 완료

- 성공 시 예매 완료 화면으로 이동한다.
- 예매번호, 영화 제목, 관람 날짜, 상영 시간, 상영관, 좌석 번호, 총 금액을 표시한다.
- 메인페이지로 이동할 수 있는 버튼을 제공한다.

## 3. 공통 규칙

| 구분 | 규칙 |
| --- | --- |
| 시간 | 날짜와 상영 시작 여부는 서버 시간을 기준으로 판단한다. |
| 검증 | 클라이언트 검증과 관계없이 서버에서 입력값을 다시 검증한다. |
| 금액 | 클라이언트가 전달한 금액을 신뢰하지 않고 서버에서 계산한다. |
| 인증 | 보호된 기능은 유효한 인증 정보를 가진 회원만 사용할 수 있다. |
| 중복 방지 | 이메일, 닉네임, 예매번호는 고유해야 한다. |
| 좌석 무결성 | 동일 상영 일정의 동일 좌석은 하나의 완료된 예매에만 포함될 수 있다. |
| 트랜잭션 | 예매와 예매 좌석은 모두 저장되거나 모두 취소되어야 한다. |

## 4. MVP 제외 범위

- 외부 결제 서비스 연동
- 좌석 임시 선점 및 만료
- 예매 취소와 변경
- 쿠폰, 할인, 포인트
- 관리자 화면 및 알림 발송
