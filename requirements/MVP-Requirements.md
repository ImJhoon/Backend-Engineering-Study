# 영화 예매 서비스 MVP 요구사항 명세서

## 1. 메인페이지 (MAIN)
- **FR-MAIN-001 영화 목록 조회:** 현재 상영 중인 영화 목록을 카드 형태(포스터, 제목, 등급 등)로 제공
- **FR-MAIN-002 영화 상세 정보:** 선택한 영화의 상세 정보(줄거리, 감독, 출연진 등) 표시 및 예매 페이지 연동
- **FR-MAIN-003 로그인 상태 표시:** 인증 상태에 따른 UI 분기(로그인/로그아웃) 및 세션 유지
- **FR-MAIN-004 예외 처리:** 목록 없음, 서버 오류 등 예외 상황에 대한 안내 메시지 노출

## 2. 회원가입 (SIGNUP)
- **FR-SIGNUP-001 정보 입력:** 이메일, 비밀번호(확인 포함), 닉네임 입력
- **FR-SIGNUP-002 이메일 검증:** 형식 확인, 중복 가입 방지, 공백 제거
- **FR-SIGNUP-003 비밀번호 검증:** 최소 8자 이상(영문+숫자 포함), 일치 여부 확인, 단방향 암호화 저장
- **FR-SIGNUP-004 닉네임 검증:** 2~20자 제한, 중복 방지, 공백 제거
- **FR-SIGNUP-005 가입 완료:** 검증 통과 시 계정 생성 후 로그인 페이지 이동 (중복 가입 요청 방지)

## 3. 로그인 및 로그아웃 (LOGIN)
- **FR-LOGIN-001 로그인:** 이메일/비밀번호 검증(보안상 실패 원인 미특정), 성공 시 토큰/세션 발급
- **FR-LOGIN-002 상태 유지:** 발급된 인증 정보로 상태 유지, 만료 시 재로그인 유도 및 API 접근 제어
- **FR-LOGIN-003 로그아웃:** 클라이언트 인증 정보 제거 및 보호된 페이지 접근 제한

## 4. 예매 (BOOKING)
- **FR-BOOKING-001 영화 선택:** 상영 일정이 존재하는 영화 목록 제공 (메인에서 진입 시 자동 선택)
- **FR-BOOKING-002 날짜 선택:** 오늘 기준 유효한 상영 날짜만 노출 및 선택
- **FR-BOOKING-003 시간 선택:** 상영관 및 잔여 좌석 수 표시 (이미 시작되었거나 매진된 회차 제외)
- **FR-BOOKING-004 좌석 조회:** 좌석 상태(선택 가능, 이미 예매됨, 사용 불가 등) 실시간 시각화
- **FR-BOOKING-005 좌석 선택:** 1회 최대 8석 제한, 선택 좌석 수에 비례한 총 결제 금액 실시간 계산
- **FR-BOOKING-006 정보 확인:** 결제 직전 영화, 날짜, 시간, 좌석, 총 금액 요약 제공
- **FR-BOOKING-007 예매 확정:** 로그인 회원 한정, 서버에서 좌석 가용성 재검증 후 고유 예매번호 발급
- **FR-BOOKING-008 동시 예매 처리:** 
  - 여러 명이 동시 선택 시 최초 완료자에게만 좌석 배정
  - 일부 좌석 선점 실패 시 전체 예매 실패 처리 (부분 예매 불가)
  - 실패 시 좌석 상태 갱신 후 재선택 안내
- **FR-BOOKING-009 예매 완료:** 예매 완료(MVP에서는 결제 완료로 간주) 내역 및 영수증 화면 제공
